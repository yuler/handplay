# HandPlay · 手机摄像头体感小游戏

基于 `@mediapipe/tasks-vision`（HandLandmarker + FaceLandmarker + PoseLandmarker WASM + WebGL2 GPU Delegate）与 **One Euro Filter** 构建的纯手机端前置摄像头体感小游戏合集，画面完全在本地浏览器推理，不上传服务器。

在线体验：**https://handplay.yuler.dev**

## 内置二十款游戏

### ✋ 单手隔空玩
1. **小花猫逗猫乐（Kitty Chase）**
   - 挥动手指变出带铃铛和羽毛的魔法逗猫棒，牵引三花小花猫跑跳扑抓小鱼干、毛线球、蝴蝶与黄金罐头，抬手跳过水洼，张手停在猫头上「摸摸头」触发呼噜双倍得分
2. **闪电结印（Gesture Rush）**
   - 单手持机，另一只手在倒计时结束前比出对应手势（✊ 石头 / ☝️ 一指 / ✌️ 剪刀 / 🖐️ 五指 / 👍 点赞 / 👌 OK）
   - 5 连击进入 **FEVER ×2** 狂热模式，并穿插「手指算数题」
3. **空气弹弓（Air Slingshot）**
   - 食指与拇指隔空捏合（Pinch）拉起底部能量弹弓，实时预览抛物线轨迹，松手弹射打爆漂浮靶标与金星，避开炸弹
4. **一指画符（Finger Rune）**
   - 食指当魔法棒，隔空画出 `—` `|` `○` `∧` `∨` 五种符咒（内置 `$1 Unistroke` + 直线几何识别），闪电连锁秒杀场上所有同符号妖怪

### 😜 完全解放双手（脸部体感）
5. **萌宠变脸秀（Animal Face Party）**
   - 模仿小狮子张大嘴、小河豚鼓腮、小熊大笑、小狗歪头、猫头鹰挑眉、小狐狸眨眼，脸上实时佩戴卡通 AR 萌宠贴纸，并支持本地生成保存「可爱变身照」
6. **大嘴吞星（Mouth Munch）**
   - 歪头操控萌宠位置、张大嘴开启漩涡狂吸星星与水果、眨眼发射双眼激光击碎冰块与怪兽、鼓腮开启护盾弹开炸弹
7. **别眨眼 / 憋笑（No Blink / Don't Laugh）**
   - 局内一键切换 **👁️ 别眨眼** 与 **😐 憋笑挑战**，躲避嗡嗡飞虫与冷笑话轰炸，破功瞬间自动抓拍并支持保存「破功照」

### 🙌 桌面支架挑战（双手同屏）
8. **彩虹泡泡乐团（Bubble Pop）**
   - 隔空戳爆飘浮的彩虹泡泡奏出五声音阶旋律，双手齐拍爆开黄金大泡泡，挥手扇飞调皮小乌云，支持单手、双手或亲子双人同屏合作
9. **左右手快闪（Dual Hand）**
   - 手机靠在桌上，同时举起左右手比出指定手势组合；热身后开启非对称脑力配对与「左右互换」突发挑战

### ✋ 单手隔空玩（续）
10. **果汁快刀**：食指划开水果，果汁跟着刀路溅开，连切加分，避开炸弹
11. **掌心弹球**：掌心把落下的球弹回去砸砖
12. **隔空钓鱼**：捏住鱼拉进桶里，松手鱼就跑
13. **捏捏果冻**：按捏合力道抓住果冻放进同色桶，捏太用力会挤爆
14. **指尖烟花**：食指画线，停住炸开并点亮灯笼
15. **食指敲鼓**：食指快速下点敲响三面鼓
16. **擦玻璃**：食指把雾抹开，露出底下的画
17. **掌心手电**：张开手掌照亮小动物，光停一会儿就把它找出来
18. **金币磁铁**：张手吸住金币，握拳倒进罐子

### 😜 完全解放双手（续）
19. **转头打地鼠**：转头选列，点头敲地鼠

### 💪 放到地上计数
20. **俯卧撑计数**：手机立在身前或身体侧面，上半身放进框里。手臂伸直、下去、手撑住再撑起来才算一次，半程不计分

## 本地开发与部署

```bash
bun install
bun run dev       # 本地预览（手机访问需 HTTPS 或 localhost）
bun run build     # TypeScript 类型检查 + Vite 打包
bun run deploy    # 打包并通过 Wrangler 部署到 handplay.yuler.dev
```
